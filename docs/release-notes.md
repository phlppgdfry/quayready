# QuayReady 0.2.0rc1

A private GitHub portfolio release candidate extending the verified E1 lab without replacing its architecture. Read [changelog](../CHANGELOG.md), [architecture](architecture.md), [release verification](release-verification.md) and [publication checklist](publication.md).

The release joins reliable integration, understandable operational UX and an independently previewable static case study. It demonstrates synthetic reconciliation, version-bound independent review, atomic outbox, separate target persistence, lost-response/restart recovery and safe terminal investigation.

The static demo is explicitly a simulation. Genuine application captures and a recorded, captioned walkthrough are separate artifacts. Python and frontend development dependencies are pinned. Automated checks include real HTTP/process tests, contract/database tests, browser/axe checks, package build and static export. The recorded Ubuntu GitHub Actions run passes all mandatory steps; see [hosted validation](hosted-validation.md) for the exact source commit, artifact records and current draft PR.

No production deployment, company affiliation, real vendor integration, physical departure authorisation, measured ROI, professional penetration test or personal mastery is claimed. The application source remains private. Release publication requires the owner's separate informed approval and an actual hosted CI run.

Reproduce using the [README](../README.md). Preview the static export under its repository subpath. Preserve old runs; reset means a new synthetic directory. Known limits and open human gates are in the verification report.

Final audit retains 0.2.0rc1: the project is complete for its local portfolio scope; hosted execution now passes, but public publication and independent human sign-off are not performed, so v1.0.0 is not asserted. See [final sign-off](final-signoff.md) and [interview package](interview-package.md). The Pages template is intentionally disabled.
