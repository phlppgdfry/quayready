# QuayReady 0.2.0rc1

A local portfolio release candidate extending the verified E1 lab without replacing its architecture. Read [changelog](../CHANGELOG.md), [architecture](architecture.md), [release verification](release-verification.md) and [publication checklist](publication.md).

The release joins reliable integration, understandable operational UX and an independently previewable static case study. It demonstrates synthetic reconciliation, version-bound independent review, atomic outbox, separate target persistence, lost-response/restart recovery and safe terminal investigation.

The static demo is explicitly a simulation. Genuine application captures and a recorded, captioned walkthrough are separate artifacts. Python and frontend development dependencies are pinned. Automated checks include real HTTP/process tests, contract/database tests, browser/axe checks, package build and static export. Hosted GitHub Actions has not run on this unpublished branch.

No production deployment, company affiliation, real vendor integration, physical departure authorisation, measured ROI, professional penetration test or personal mastery is claimed. The application source remains private. Release publication requires the owner's separate informed approval and an actual hosted CI run.

Reproduce using the [README](../README.md). Preview the static export under its repository subpath. Preserve old runs; reset means a new synthetic directory. Known limits and open human gates are in the verification report.
