# QuayReady 0.2.0rc2 — public portfolio source

Public showcase: **https://phlppgdfry.github.io/quayready/**. Source and tests: **https://github.com/phlppgdfry/quayready**.

This release makes the existing, working synthetic logistics lab independently inspectable. It adds public source navigation, anonymous clone instructions and current publication/security documentation. The Python/FastAPI/SQLite architecture, deterministic readiness rules, independent review, atomic outbox, actual local HTTP target, bounded retries, fencing and recovery behavior are preserved. No new product features, vendor integrations, frameworks or dependencies are introduced.

The public browser demo is explicitly a simulation. Genuine application captures and the captioned recording are separate evidence. Source availability does not imply a running public backend, a real WMS/TMS integration, physical departure authority, company endorsement, professional client delivery, measured ROI or production compliance.

The established suite, API response coverage, clean-wheel installation, hosted CI, Pages build, public HTTP/asset checks and Chromium workflows are executed before sign-off. Actual commands, counts, commit IDs and conclusions belong in the release's publication evidence; they are not inferred from these notes. Personal mastery and independent human reproduction remain separate, unverified learning gates.
