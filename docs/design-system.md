# Design system

An evidence desk, not a collection of dashboard widgets. Show missing items, ownership and the next safe action before technical history. Public visitors see the same brand through workflow lanes, a reliability timeline and component explorer rather than another dashboard.

Palette: harbour #183b53; paper #f4f7f9; ink #172e40; secondary ink #496171; line #ccd8df; amber #85520b; green #23624e; red #a1323a. White surfaces and one harbour identity rail keep attention on evidence. Status always includes text. System typography uses Avenir Next / Segoe UI / sans-serif, with monospace for real identifiers only. No external font licensing or download dependency.

Type sizes 40/32/24/18/15/13px, line-height 1.5, body measures under 75 characters. Spacing 4/8/12/16/24/32/48/64px. Restrained 6–10px corners, bordered controls, 44px tap targets, persistent labels, high-contrast 3px focus outlines. Disabled/busy actions describe progress; errors receive focus and show safe next actions. No decorative motion; reduced-motion preference is honoured.

Desktop uses a narrow navigation rail and fluid evidence workspace. Tablet turns the rail into a top band. Below 760px, source columns stack, metrics become two columns and audit events become list items rather than compressed table cells. No fixed-height scroll traps. Public navigation is anchor-based and refresh-safe under a repository subpath.

Assets: original MIT vector diagrams and genuine application captures. No copied corporate imagery, tracking, stock photography or generated fake application screenshots. See release verification for actual checks; this is not WCAG certification.
